En desarrollo🔒 Código privado01

Monitoreo Inteligente de NVR y Cámaras

Plataforma de supervisión para sistemas de videovigilancia: además de detectar desconexiones, verifica que cada cámara realmente esté viendo, grabando y con la hora correcta, y revisa la seguridad de los equipos.

  • Monitoreo de cámaras personalizado y multiservidor
  • Detección de desconexiones en tiempo real con alertas por Telegram
  • Detección de desfases entre la hora OSD de la cámara y la hora actual
  • Detección de imagen borrosa o nula y de visión nocturna no operativa
  • Reporte de tiempo de grabación, intermitencias y pérdidas de grabación
  • Detección de vulnerabilidades en NVR y cámaras
  • Seguimiento de personas, rostros u objetos con IA

Editor de Video con Difuminado de Rostros

Aplicación para reproducir videos y difuminar rostros o formas de forma manual o automática con IA, protegiendo la identidad de las personas en grabaciones.

  • Detección automática de rostros y formas con YOLOv8
  • Difuminado manual con seguimiento (tracking) de objetos
  • Reproducción hasta x16, saltos por bloques y frame a frame
  • Progreso guardado en JSON para continuar sin reprocesar
  • Exportación con FFmpeg y aceleración GPU (DirectML), o solo CPU

Editor Inteligente de Fotos de Identificación

Herramienta para preparar fotos de fotocheck y fotocarnet en segundos. Convierte fotos difíciles —selfies, baja calidad, fondos irregulares— en fotos de identificación listas para imprimir, manteniendo el control del usuario en cada paso.

  • Procesa fotos complejas: selfies, poca luz o baja resolución
  • Recorte configurable con proporciones de identificación
  • Vista previa de cada cambio antes de aplicarlo
  • Flujo rápido pensado para alto volumen de fotos
  • Versión de escritorio para procesamiento masivo (en desarrollo)

Nuevo🔒 Código privado05

Candado: Bloqueo de Carpetas con PIN

Aplicación de escritorio para Windows que oculta y protege carpetas de trabajo en equipos compartidos, sin instalar software adicional ni mover los archivos de lugar.

  • Teclado numérico en pantalla con orden aleatorio (anti-keylogger)
  • La clave se guarda solo como hash, nunca en texto plano
  • Historial de intentos de acceso con fecha y hora
  • Bloqueo y autodestrucción tras 100 intentos fallidos
  • Ejecutable portable (.exe), sin instalación
